# CtaBox

The closing call to action: a centred box with a large heading, one sentence, and a primary plus secondary button.

**Consumer provides:** an `h2` (`heading-cta`), one paragraph up to 640px wide, and `.cta-btns` with a WhatsApp `btn-primary` and an optional `btn-secondary`.

- Max width 880px, padding `space-xl`, `radius-xl` (the only place it's used), `hairline-strong` border, `brand-tint-strong` → `brand-tint` fill, `shadow-lift`.
- The last section on every page, above the footer.
- Follows the conversion path Low Friction → Fast Connection → Human Close: the copy promises a quick, personal reply.
