# Footer

The page footer: the wordmark with a one-line descriptor and contact on the left, a short row of links on the right.

**Consumer provides:** the split wordmark, one or two `.small` lines (descriptor, location, WhatsApp number as plain text), and 3–6 links.

- `hairline` top border; text `ink-muted`; links turn `brand` on hover. The wordmark uses 0.28em tracking (a touch tighter than the nav's 0.32em).
- Always show the WhatsApp number as text, not only as a link.
