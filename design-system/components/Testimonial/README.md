# Testimonial

A client testimonial: five stars, a large open-quote mark, the quote in the display serif, and an attribution footer.

**Consumer provides:** the quote as `<p>`s inside `.t-body` (mark the closing line `t-emph`), and `.t-attr` with a `<strong>` descriptor ("Verified Clarity Mapping Client") and a place.

- Solid `surface-raised` fill so it reads as an object; `hairline` border, `radius-lg`, `shadow-lift`.
- Body is `quote` in `ink`; the emphasised line is `brand-bright`.
- Clients are anonymised by default: describe them by the service they bought, not by name, unless they've agreed to be named.
- Two-up grid with a 26px gap, one column at 820px and below.
