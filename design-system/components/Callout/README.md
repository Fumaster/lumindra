# Callout

A tinted block with a 3px `brand` rule on its left edge: `founder-block` for the indexable founder statement, `insight` for a short lesson in a case study.

**Consumer provides:** a paragraph (founder-block, with the key sentence in `<strong>`) or an `h4` + paragraph (insight).

- `brand-tint` fill, `radius-sm` (founder) or `radius-md` (insight).
- This left-rule treatment comes from the live site. Keep it to these two uses; don't add it to cards or panels.
